1. What the Bot is

19 Bot is a moderation and utility application for Discord. It is operated for The Submission Server and provided free of charge. It offers:

  • Moderation tooling: auto-renewing timeouts, an after-ban list, and a new-member probation role
  • Security automation: kicking bots that are not on an allow list, flagging newly created accounts, and blocking links from new members
  • Content automation: announcing new posts from a fixed set of RSS feeds
  • Utilities: reference diagrams, a rules link, and staff event scheduling
  • An owner-only channel archiving command
